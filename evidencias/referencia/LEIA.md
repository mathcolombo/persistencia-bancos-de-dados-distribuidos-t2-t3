# Como interpretar referências

Resultados fornecidos nos enunciados são referências didáticas, não logs do grupo. Os exemplos de consultas não provam que os servidores foram executados.

Neste pacote não há logs fabricados de banco, réplica, migração ou recuperação. Os arquivos em evidencias/execucoes são criados somente quando os comandos são executados no computador do usuário.
